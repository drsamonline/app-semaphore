One sync with any device that holds them → Ravi has both, in the original order, numbered 01 and 02. Not a replay, not a summary: the same two messages.

One sync is enough

A device that was away asks for everything after what it already has, so the catch-up is one exchange rather than a replay of the whole conversation.

What it refuses

It will not let a non-host edit the bulletin, and with low-power mode on it will not attach an image or a voice note at all — a refusal, not a warning.

Semaphore

Messages and a pinned bulletin for a group. A device that was away catches up in one sync — in the original order.

Open Semaphore

The LAN transport is not built. There is no WebSocket, no multicast and no Bluetooth here: the page keeps two copies of the group and syncs them through the same operation a hotspot link would carry.

Status Built and working: messages with a sender and an optional attachment; a catch-up that brings an absent device everything it missed after one sync, in time order; a bulletin only the host can edit, which reaches every member; and low-power mode that refuses images and voice notes.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: the transport, and therefore real multi-device messaging; also no encryption. Messages are plain text on each device.

What it does

  • Posts a message with a sender, and an optional attachment.
  • Catches an absent device up after one sync, in time order, with nothing duplicated.
  • Keeps a bulletin that only the host can edit, and that reaches every member.
  • Refuses an image or voice note while low-power mode is on.

What it will not do

  • Claim a transport it does not have. The LAN link is named as absent.
  • Let a non-host edit the bulletin. The refusal names whose it is.
  • Accept an attachment in low-power mode.
  • Start an empty group over a broken one — that looks like everyone went quiet.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputNo group name, no host, no sender, an empty message, a sync between two different groups — each refused with the field named.
No networkNothing changes; there is no network code.
Storage full or unavailableNOT SAVED, and the group on screen is unchanged.
Corrupt saved stateReported and offered for export; never replaced with an empty one.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
